# 6. Step-by-step

ข้อมูล:

`4 10 3 5 1 8 7 9 2 6`

## Algorithm A

| ขั้น | Insert | Array |
|---|---:|---|
| 1 | 4 | `[4]` |
| 2 | 10 | `[10, 4]` |
| 3 | 3 | `[10, 4, 3]` |
| 4 | 5 | `[10, 5, 3, 4]` |
| 5 | 1 | `[10, 5, 3, 4, 1]` |
| 6 | 8 | `[10, 5, 8, 4, 1, 3]` |
| 7 | 7 | `[10, 5, 8, 4, 1, 3, 7]` |
| 8 | 9 | `[10, 9, 8, 5, 1, 3, 7, 4]` |
| 9 | 2 | `[10, 9, 8, 5, 1, 3, 7, 4, 2]` |
| 10 | 6 | `[10, 9, 8, 5, 6, 3, 7, 4, 2, 1]` |

## Algorithm B

เริ่มจาก Array เดิม

`[4, 10, 3, 5, 1, 8, 7, 9, 2, 6]`

เริ่ม Heapify จาก index `4` ลงมาถึง `0`

```text
index 4 -> [4, 10, 3, 5, 6, 8, 7, 9, 2, 1]
index 3 -> [4, 10, 3, 9, 6, 8, 7, 5, 2, 1]
index 2 -> [4, 10, 8, 9, 6, 3, 7, 5, 2, 1]
index 1 -> [4, 10, 8, 9, 6, 3, 7, 5, 2, 1]
index 0 -> [10, 9, 8, 5, 6, 3, 7, 4, 2, 1]
```

ผลสุดท้ายเป็น Max Heap ที่ถูกต้อง
