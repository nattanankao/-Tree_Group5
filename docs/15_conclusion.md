# 15. สรุป Algorithm ที่เหมาะสมกับสถานการณ์

ทั้งสอง Algorithm ให้ Max Heap ที่ถูกต้อง แต่เหมาะกับสถานการณ์ต่างกัน

- ถ้า Job เข้ามาทีละรายการและต้องรักษา Heap ให้พร้อมใช้งานตลอดเวลา การใช้ `INSERT + heapifyUp` เหมาะกับรูปแบบการทำงานนี้
- ถ้ามี Job จำนวนมากอยู่ในข้อมูลตั้งแต่แรกและต้องการสร้าง Heap ครั้งเดียว การใช้ Bottom-Up Build Heap มี Complexity เป็น `O(n)` ตามทฤษฎี

ดังนั้นการเลือก Algorithm ควรดูจากรูปแบบการรับข้อมูล ไม่ใช่ดูเฉพาะ Complexity เพียงอย่างเดียว
